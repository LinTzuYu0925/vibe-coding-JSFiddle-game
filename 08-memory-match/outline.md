- 起始遊戲：記憶翻牌 Memory Match，fiddle 待老師建立（原始碼已完成：`08-memory-match/starter/memory-match-0.html`，救援 1–3 同資料夾；網址填在 `components/Fiddle.vue`）
- 起始遊戲已經有的（HTML／CSS 都做好，學生只改 JavaScript）：
  - 開始畫面＋「開始」按鈕（按了會進入遊戲，這部分已經能動）
  - 12 張蓋著的牌（6 對 emoji），JS 用 `const emojis = [...]` 洗牌後排成 4×3
  - 上方「步數 0 / 20」顯示、隱藏的勝利畫面、失敗畫面、「再玩一次」按鈕
  - CSS 已寫好 `flipped`（翻開）、`matched`（配對成功）、`shake`（晃一下）；藏起來的 ⏱ 倒數（給「我的版本」用）
  - 開始畫面蓋住整個桌面，所以「按開始前點牌」本來就點不到
  - **還不能做的**：點牌沒反應、不會比對、步數不會動、不會贏也不會輸
- 這堂課的目標：
  ① 用四格 Prompt 寫出自己的第一個改法，並在 ☁️ Save 前先玩過、確認 AI 給的程式真的能用
  ② 做出一個用滑鼠玩、可以贏也可以輸的記憶翻牌遊戲（Classroom 交的版本能玩到兩種結局）
  ③ 說出這個遊戲的目標、規則、挑戰、回饋（遊戲設計四個字）
- 本堂教學重點（依 COURSE-PLAN.md 六條主線，跟 AI 合作最優先）：
  - A 跟 AI 合作：**AI 也會出錯，每次回答也不一樣 → 先玩再存**；要 AI 給「完整」的 JavaScript；第一次自己寫四格 Prompt
  - B 遊戲設計：遊戲設計四個字（目標／規則／挑戰／回饋）；本堂重點挑戰＋回饋；完整遊戲在 STEP 3 完成
  - C 遊戲怎麼想：事件（滑鼠點一下）、變數（記住第一張牌）、隨機（洗牌）、計時（等 1 秒）
  - D 測試與除錯：數字先改小再測（20 → 3）、症狀表、回報句
  - E 電腦與網路：第一個只用滑鼠玩的遊戲
  - F 數位公民：⭐ 喜歡的一點＋💡 一個點子（夥伴試玩）
- 上一堂學生會的（第 2–7 堂，deck 02–04）：Fork、☁️ Save、遊戲編號／版本編號、四格 Prompt、貼最新的程式碼、
  一次改一件事、用 raw URL 加音效、完整遊戲（開始／遊玩／勝利／失敗／重玩）
- 不教：只回傳改過的函式（第 10 堂）、更多關卡（第 10–11 堂）、陣列 Array 的寫法（只說「一串 emoji」）、
  `setTimeout` 的語法（只說「等 1 秒」）
- 改程式的方式：整段 JavaScript（遊戲還短）
- Prompt 填空階梯（COURSE-PLAN.md §5）：STEP 1 填 2 格（選一個＋數字）→ STEP 2 填 4 格（＋④ 一整格，有字庫）→ STEP 3 填 5 格（① ③ 整格，有字庫）→ 我的版本四格全空。答案都在該 STEP 的目標頁；老師寫好情境句、HTML id／CSS class、要完整 JavaScript 那一句和貼程式的格子
- Classroom 作業名稱：「第 8 堂：記憶翻牌」。作業裡有一個**選填**的「設計卡」欄位（目標／規則／挑戰／回饋），
  想寫的同學打幾個字就好，不寫也可以，用說的就算數。
